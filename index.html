HOW WE BUILD · 만드는 방식

원문에서 화면까지,
한 줄로 이어지게

계산 규칙은 원문에서 나오고, 계산은 이용자의 기기 안에서 끝나며, 화면은 가볍게 유지합니다.

STEP 01

원문 기반 계산 규칙

법령·시행령·고시 원문에서 계산식과 조건을 옮기고, 어느 조항인지 함께 적어 둡니다.

STEP 02

기기 안에서 계산

입력값을 서버로 보내지 않고 휴대폰 안에서 바로 계산합니다. 그래서 개인정보를 받을 일이 없습니다.

STEP 03

가벼운 화면

첫 화면이 1초 안에 뜨는 것을 목표로, 꼭 필요한 것만 싣고 무거운 것은 뒤로 미룹니다.

STEP 04

출시 후 개선

기준이 바뀌거나 헷갈리는 화면이 보이면 원문부터 다시 확인하고 고쳐 내보냅니다.

개선은 다시 원문 확인으로 돌아가는 반복입니다

rule.js · 예시
// 원문: 근로기준법 제55조, 제18조제3항
// 고시: 고용노동부고시 제2025-47호 (2026년 시간급)
const 최저시급 = 10320;

function 주휴시간(주근로시간) {
  if (주근로시간 < 15) return 0;
  return Math.min(주근로시간, 40) / 40 * 8;
}
// 계산은 기기 안에서만. 입력값은 전송하지 않음
조항을 같이 적는다숫자 옆에 근거 조항을 남겨, 기준이 바뀔 때 어디를 고칠지 바로 찾습니다.
보내지 않는다계산에 필요한 값은 화면 안에서만 쓰고, 서버에 저장하지 않습니다.
가볍게 유지한다첫 화면 1초를 목표로 그림과 코드를 줄이고, 필요한 순서대로 불러옵니다.

FAQ · 자주 묻는 질문

자주 묻는 질문

더 궁금한 점은 아래 메일로 보내 주세요.

개인정보를 받나요?

받지 않습니다. 미니앱과 도구는 이름·연락처·주민등록번호를 묻지 않고, 계산은 이용자의 기기 안에서 처리합니다. 문의 메일을 보내신 경우에만 답변을 위해 이메일 주소와 문의 내용을 받습니다. 자세한 내용은 개인정보처리방침에 있습니다.

이용하는 데 비용이 드나요?

미니앱은 무료로 쓸 수 있으며, 일부 화면에 플랫폼이 제공하는 광고가 표시될 수 있습니다. 디지털 상품과 생활 상품은 유료로 판매합니다.

계산 결과는 정확한가요?

법령과 공식 고시 원문을 기준으로 계산하지만, 결과는 참고용입니다. 실제 지급액·자격·세액은 개인 사정과 해당 기관의 판단에 따라 달라질 수 있으니, 최종 확인은 담당 기관에서 해 주세요.

어디에서 쓸 수 있나요?

미니앱은 토스 앱 안에서 열어 쓸 수 있습니다. 따로 설치하지 않아도 됩니다.

법이나 기준이 바뀌면 어떻게 하나요?
